# Worked example: a brief for a food and team photographer

Tallyhouse is a fictional restaurant bookkeeping firm. The files:
- `request.md`: what the user asked for
- `brand/`: the brand memory read
- `briefs/agency/team-photos.md`: the brief
- `briefs/agency/team-photos-brand-extract.md`: the brand pack, drafted from brand memory and then edited for a photographer
- `reply.md`: the reply to the user

## What to notice

| Choice | Why |
|---|---|
| Budget, payment, shoot week and delivery date are exactly as given | They're the user's. The shoot day, image count and formats weren't given, so they're `TBD` and listed first in the reply |
| The 3-day claim is under "Claims not to use" | It's on the website but unsubstantiated. A photographer writing captions might copy it |
| The Lantern quote carries a naming note in the pack itself | Permission is unconfirmed. A warning only the user sees protects no one |
| Releases, usage rights, portfolio use, one edit round and image descriptions are in the brief | They're proposals, so the reply lists them for the user to confirm before sending |
| The pack is cut for a photographer | Prices and the reach-out rule aren't needed for a shoot. The voice rules are translated into what they mean for pictures |
| No success target | The user gave none, so the brief names how the images will be used rather than inventing a number |

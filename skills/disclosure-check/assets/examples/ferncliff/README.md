# Worked example: a Ferncliff LinkedIn post that comes back Fix first

Ferncliff is a fictional dental scheduling company. The files:
- `linkedin-post.md`: the post
- `brand/`: the parts of brand memory the check reads (countries, prices, the testimonial's relationship)
- `linkedin-post-disclosures.md`: the report, which is also the reply

## Why Fix first and not Hold

Both problems can be fixed with facts already in brand memory: `proof.md` records that Dr. Lewis is an investor, and `offer.md` has both prices. Nothing needs the user's input, and nothing in the post is beyond what a disclosure can fix.

## What it didn't flag

- **The `?ref=linkedin` link.** It looks like an affiliate parameter, but it's Ferncliff's own domain on Ferncliff's own page: a channel tag, not a paid relationship.
- **US rules.** Brand memory says Ferncliff sells in Canada only, so the check names Canadian rules alone.
- **The quote itself.** It's recorded word for word in `proof.md` with permission to name her.

Each fix is the exact replacement line, so whoever posts it doesn't need to ask a follow-up question.

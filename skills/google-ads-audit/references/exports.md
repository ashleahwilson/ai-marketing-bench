# What to export

Send this list, with the "Where in Google Ads" column, when there's no data, or when a check can't run because a file is missing. Ask for CSV downloads from the Google Ads web interface, for the same date range on every report: the last 90 days is best, 30 days is the minimum for a confident read.

| # | Report | Where in Google Ads | Columns that matter |
|---|---|---|---|
| 1 | Campaigns | Campaigns, all enabled | Budget, Bid strategy type, Target CPA / ROAS, Clicks, Impr., Cost, Conversions, Conv. value, Search impr. share, Search lost IS (budget), Search lost IS (rank) |
| 2 | Campaigns by network | Campaigns, Segment > Network (with search partners) | Cost, Conversions |
| 3 | Campaign settings | Campaigns, add columns Networks, Locations, Location targeting (or one screenshot per campaign's Settings page) | Networks, Locations, Location targeting option |
| 4 | Keywords | Keywords > Search keywords | Match type, Quality Score, Exp. CTR, Ad relevance, Landing page exp., Cost, Conversions |
| 5 | Search terms | Insights and reports > Search terms | Search term, Match type, Campaign, Ad group, Cost, Conversions |
| 6 | Negative keywords | Keywords > Negative search keywords, plus any negative keyword lists | Negative keyword, Match type, Level |
| 7 | Ads and assets | Ads, all responsive search ads | Ad type, Ad strength, Final URL, Headlines 1–15, Descriptions 1–4 |
| 8 | Conversion actions | Goals > Conversions > Summary | Conversion action, Source, Category, Action optimization (Primary/Secondary), Count, Value, Conversions |
| 9 | User locations (optional) | Insights and reports > When and where ads showed > Locations, "User location" | Country/Territory, Cost, Conversions |

Leave the title and date lines at the top of each download as they are: they carry the date range. Put every file in one folder and say where it is.

**Connected Google Ads tool?** If one is available, read the same data with it, read-only. The audit never changes the account.

Also useful, if not already in brand memory: what a conversion is worth (or the target cost per lead or sale), the monthly budget, and the brand names and misspellings to treat as brand searches.

# Worked example: Quillmetrics maps Oakline Outfitters

Fictional companies, no claimed results. Quillmetrics sells revenue analytics for Shopify stores (its brand memory has no audiences file, so personas are provisional).

**The request:** "Map Oakline Outfitters from accounts/oakline/ and tell me who to start with."

**Inputs:**
- [accounts/oakline/team-page.md](accounts/oakline/team-page.md), saved 2026-10-12
- [accounts/oakline/crm-export.csv](accounts/oakline/crm-export.csv), exported 2026-10-12
- [accounts/oakline/call-notes-2026-10-07.md](accounts/oakline/call-notes-2026-10-07.md)

**Outputs:**
- [reply.md](reply.md): what the user sees
- [accounts/oakline/contacts.md](accounts/oakline/contacts.md): the hand-off file for outreach drafting

What it shows: a champion with evidence, an economic buyer named by a colleague, a CRM contact who has left (moved to Not contacting), a stale CRM title, a technical evaluator gap, and no blocker assigned without evidence.
